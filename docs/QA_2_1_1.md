# Laporan QA — Leinz Lens Studio 2.1.1

> Catatan historis tahap perubahan UI. Pengujian ulang database dan paket lengkap setelah tahap ini tersedia pada [QA_RELEASE_2_1_1.md](QA_RELEASE_2_1_1.md).

Tanggal pemeriksaan: **4 November 2026**. Cakupan patch ini adalah penataan
kontrol Studio agar pemilihan bentuk, ukuran frame, resep dan sentrasi berada
di atas tint terpilih. [Laporan QA 2.1](QA_2_1.md) tetap menjadi catatan pengujian
instalasi, pengelolaan master, model optik, dan MySQL 5.7.24 sebelumnya.

## Perubahan yang diperiksa

- SKU produk finish, indeks, dan produk bahan baku dipindah ke area
  Perbandingan pasangan A/B dengan tombol pemilih pasangan aktif.
- Panel Frame & resep menempatkan bentuk/ukuran dan resep/sentrasi sebelum tint.
- Pemilihan bentuk tersedia melalui dropdown ringkas dan galeri yang dapat
  dibuka. Keduanya memakai jalur pemilihan dan kontur master yang sama.
- Label tint menunjukkan pasangan aktif; frame dan resep diberi keterangan
  bahwa pengaturannya berlaku untuk kedua pasangan.
- Urutan DOM mengikuti tampilan panel pada layar sempit. Label bentuk arsip
  tetap terlihat, dan indikator buka/tutup galeri mengikuti keadaan galeri.

## Pengujian otomatis

`npm test` selesai dengan **exit code 0**. Perintah tersebut juga menjalankan
pemeriksaan sintaks, referensi aset HTML, serta katalog JSON.

| Pemeriksaan | Hasil |
| --- | ---: |
| Sintaks source JavaScript | 30 berkas valid |
| Referensi aset HTML dan katalog JSON | Lulus |
| Master SKU | 24 pengujian lulus |
| Backend dasar, storage, konsultasi, validator master, Manage dan optik | 97 pengujian lulus |
| Total pengujian bernama | **121 lulus, 0 gagal** |
| Blank engine | Suite assertion lulus |
| Lens viewer | Suite assertion lulus |

Pemeriksaan struktur HTML tidak menemukan ID duplikat. Kontrol yang dipindah
mempertahankan ID dan handler semula. Tidak ditambahkan salinan input SKU,
indeks, atau produk yang dapat menimbulkan state terpisah.

## Pengujian antarmuka

Pemeriksaan dilakukan pada preview mode browser melalui kontrol aplikasi.

| Skenario | Hasil yang diamati |
| --- | --- |
| Panel Frame & resep | Dropdown bentuk, A/B/DBL, resep dan sentrasi tampil di atas tint terpilih |
| Pasangan aktif | Memilih B dan mengganti indeks B menjadi 1.67 mempertahankan indeks A 1.74; judul pengaturan dan label tint mengikuti B |
| Kembali ke A | Indeks masing-masing pasangan tetap tersimpan dan penanda aktif kembali ke A |
| Dropdown Rounded | Kedua preview dan pilihan shape pada pemeriksaan blank ikut diperbarui |
| Lebar dan resep | Mengubah lebar menjadi 54 mm serta SPH menjadi −5 memperbarui kedua preview |
| Galeri Rectangle | Pilihan pada dropdown dan ukuran awal mengikuti bentuk yang dipilih melalui galeri |
| Galeri tertutup | Chevron menunjukkan keadaan tertutup saat bagian bentuk utama tetap terbuka |

### Posisi kontrol dan overflow

| Viewport yang diperiksa | Hasil |
| --- | --- |
| 1363 × 936 piksel | Input sentrasi terakhir (`rx-height-l`) berakhir pada y = 759,34 piksel, sehingga seluruh input resep dan sentrasi berada dalam viewport. Tidak ada overflow horizontal. |
| 1366 × 768 piksel | Seluruh input ukuran, resep, dan sentrasi terlihat tanpa scroll pada posisi awal; input terakhir berakhir pada y = 759,34 piksel. Tint dimulai pada y = 822,84. Tidak ada overflow horizontal. |
| 1000 × 768 piksel | Panel Frame & resep muncul sebelum preview. Input sentrasi terakhir berakhir pada y = 751,30 piksel, sebelum tint (y = 787,80). Tidak ada overflow horizontal. |
| 390 × 844 piksel | Frame dan resep tetap sebelum tint. Kolom produk membungkus menjadi dua kolom, lalu bahan memakai satu baris penuh. Tidak ada overflow horizontal. Scroll vertikal tetap diperlukan pada layar ponsel; input sentrasi terakhir pada y = 881,97 piksel. |

Pemeriksaan tiga ukuran tambahan memakai iframe dengan viewport tetap melalui kontrol browser. Log error/warning dari origin preview tidak ditemukan selama interaksi yang diperiksa. Draft bentuk, dimensi, resep, dan indeks tetap terbaca setelah navigasi ulang.

Perbaikan `display: block` pada input resep menghilangkan overflow dari susunan
empat kolom. Bukti posisi di atas berlaku pada viewport dan keadaan galeri
tertutup yang diuji.

## Database dan batas pengujian

Versi 2.1.1 tidak mengubah query, skema SQL, rumus CT/ET, atau isi master bawaan.
Pengujian MySQL 5.7.24 secara langsung **tidak diulang pada patch ini**. Hasil
integrasi database dan instalasi bersih sebelumnya tetap tercatat di
[QA 2.1](QA_2_1.md); hasil tersebut tidak dihitung sebagai pengujian baru 2.1.1.

QA UI patch ini berfokus pada kontrol yang dipindah, pemilihan bentuk, perubahan
dimensi/resep, dan cakupan pasangan A/B. Tidak semua alur aplikasi diuji ulang
secara manual pada patch ini.

## Pembaruan instalasi

- Dari **2.1.0**: perbarui paket aplikasi sambil mempertahankan `.env` dan
  database, restart layanan, lalu muat ulang halaman. Tidak ada migrasi SQL baru.
- Dari versi **di bawah 2.1**: jalankan langkah migrasi 2.1 yang tercantum dalam
  [panduan MySQL](INSTALL_MYSQL57.md), termasuk `db:migrate` dan `db:seed`.

Pemeriksaan ini menunjukkan hasil yang diamati pada cakupan tersebut; tidak
menyatakan bahwa setiap ukuran layar, browser, dan kombinasi input telah diuji.
